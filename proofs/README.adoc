= Groove protocol proofs (relocated from gossamer — WIRED & GATED here)
:toc: macro

[abstract]
Three Idris2 proof modules moved *wholesale* out of `hyperpolymath/gossamer` on
2026-06-16 (via the interim `groove` repo, consolidated here 2026-07-02 per ADR
0001). As of 2026-07-27 (owner ruling: *finish the relocation*) they are
**wired and machine-verified in this repo**: `groove-proofs.ipkg` builds them
against byte-identical vendored copies of `Gossamer.ABI.{Types,Groove}`
(`proofs/VENDOR.json` pins the upstream commit; CI diffs on every run), and the
`proofs` workflow is a REAL gate (ipkg `--typecheck`, no `continue-on-error`).

== What is here

[cols="1,3",options="header"]
|===
| Module | What it proves (over the gossamer-era ABI)
| `GrooveTermination.idr` | Completed abstract traces have ≤4 steps; compatibility values contain subset evidence. Its named determinism witness is predicate reflexivity, not terminal-outcome uniqueness; the trace transitions permit both unguarded acceptance and rejection.
| `IPCDispatch.idr` | IPC command dispatch + protocol-conformance (`ConformsTo`) machinery for the groove command surface.
| `CapabilityAuthenticity.idr` | Table coverage and membership, structural attenuation, and evidence that both named IDs are in one revocation set. It does not prove that a numeric handler address implements the capability or that native calls enforce the model.
|===

== Status — WIRED, VERIFIED, DRIFT-GUARDED (2026-07-27)

Layout: `proofs/Gossamer/ABI/` holds the three proof modules plus the two
vendored dependencies, matching their declared `module Gossamer.ABI.*` names.

* `groove-proofs.ipkg` (repo root) typechecks all twelve modules; the `proofs`
  workflow runs it on every PR/push touching `proofs/**` (plus weekly cron).
* `Types.idr` and `Groove.idr` are **byte-identical vendored copies** of the
  gossamer sources, pinned to an upstream commit in `proofs/VENDOR.json`. The
  `vendor-integrity` CI job diffs them against that pin — edit them upstream,
  never here.
* The module names stay `Gossamer.ABI.*` **deliberately**: the cross-repo proof
  agreement check compares theorem surfaces by module name; a rename would break
  comparability. The `Groove.*` rename is a separate, future decision.
* The gate is ipkg-based on purpose: idris2 0.7.0 `--check file.idr` exits 0 on
  module-load errors (measured 2026-07-27), so a per-file loop is a fake gate.
* `GrooveProxy.idr` is **in the package** (moved from `reference/groove-proxy/`,
  2026-07-27): its `TypedFrameRouter*` dependencies are vendored byte-identical
  from `proven-servers` (fixed there in hyperpolymath/proven-servers#57 — the
  `noReverseTranslation` lemma was TRUE all along; the old proof style plus the
  lowercase auto-bind trap were the blockers), and `grooveNoReverse` is now
  proved via the repaired general lemma.

== PROOFS-1 — remaining evolution (open)

Local recheck on 2026-09-05 used Idris2 0.7.0 and 0.8.0 with fresh build directories:
all twelve modules and the positive fixture passed. Negative controls reject
parent-only revocation evidence and arbitrary-path-to-AppData attenuation.
Run `bash tests/check_proofs.sh /absolute/path/to/evidence` to reproduce.
Set `IDRIS2` to the desired compiler executable. CI pins 0.8.0; a local result
does not assert a new remote CI run.

The corrected revocation witness binds both IDs to the same revocation set;
it is not a transitive descendant-discovery algorithm. The finite handshake
model does not prove eventual delivery or termination of a network peer under
message loss. No proof-to-Rust or proof-to-Zig refinement is claimed.

The relocation itself is finished. What remains of the original PROOFS-1 vision
is the *re-founding*, still open:

. Rename modules `Gossamer.ABI.*` → `Groove.*` — only together with the
  cross-repo agreement-check design, since it breaks name-based comparability.
. Re-state the proofs against the v0.2 manifest data model in `SPEC.adoc`
  instead of the vendored gossamer ABI (a semantic re-founding, not a port).

Do the rename only under the CI job that can check it — a textual rename with no
typechecker is churn, not progress.

== What stayed behind (context)

The **cleave-obligation** proofs `HandleLinearity.idr` (linear handles) and
`ResourceCleanup.idr` (teardown / residue) stayed in gossamer: they are generic
(they prove over `WebviewHandle`/`Channel`/`Cap`, not just groove) but still
`import Gossamer.ABI.Groove`. Their decoupling belongs to the cleave repo's
PROOF-NEEDS ledger, not here. The groove *native* surface (`groove.zig`,
`gossamer_groove_*` exports, `schema/groove-manifest.schema.json`) also remains in
gossamer, blocked on a green native build there.
